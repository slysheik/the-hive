# BLOG POST DRAFTER — Claude Template

Run this in Claude after personally completing an offer.
Never run this before you have real data from the offer.

---

```
Write a first-person blog post for The Hive Kenya blog.

MY OFFER DATA:
Platform: [name]
Date started: [date]
Date completed: [date]
Actual deposit I made: KES [amount] (or "none")
Actual bonus I received: KES [amount]
Actual fees I paid: KES [amount]
Net I walked away with: KES [amount]
Hours I spent: [hours]
Complications I encountered: [describe any issues, delays, surprises — or "none"]

WRITE:
- Length: 600–800 words
- Tone: honest, practical, first person — like a message to a friend who asked for advice
- No hype, no promises, no marketing language
- Use specific KES numbers throughout — never convert to USD

STRUCTURE (follow this exactly):
1. What I did (2–3 paragraphs): How I found the offer, what I signed up for, what the offer promised
2. What happened (2–3 paragraphs): The actual experience step by step — including any friction, delays, or surprises
3. The math (1 paragraph with a simple table):
   | Item | Amount |
   |---|---|
   | Deposit | KES [X] |
   | Bonus received | KES [X] |
   | Fees paid | KES [X] |
   | Net profit | KES [X] |
   | Time spent | [hours] |
   | Effective hourly rate | KES [X]/hr |
4. My verdict (1 paragraph): Is it worth it? Who should try it? Who should avoid it?
5. Closing CTA (2 sentences): Link to the offer card on The Hive. Include affiliate disclosure.

AFFILIATE DISCLOSURE (mandatory at the end):
"This post contains affiliate links. If you sign up through my links, I earn a commission. This doesn't affect my review — I only write about offers I've personally completed."

GENERATE THE TITLE AND META DESCRIPTION ALSO:
Title: [Kenya-specific, includes platform name, 50–60 characters]
Meta description: [includes KES net figure, 120–155 characters]
```

---

## When to Use This

- Immediately after completing a personal offer test
- When you have all real data filled in above
- Never use estimates — only actual recorded numbers

## What to Do With the Output

1. Read through the entire draft — Claude follows structure but you know the experience
2. Add any detail Claude missed from your personal experience
3. Edit any sentence that sounds like AI — make it yours
4. Publish to Astro blog
5. Cross-post to Medium (same day or next day)
6. Share in Kenyan Telegram/WhatsApp communities within 48 hours of publishing
